# الحوت ستور
نسخة أولى ثابتة لمتجر إلكتروني عربي.

## التشغيل
افتح `index.html` في المتصفح.

## أهم تعديل قبل النشر
افتح `script.js` وعدّل:
WHATSAPP="201023466292";
إلى رقم واتساب المتجر بدون علامة +.

## التعديل على المنتجات
كل المنتجات التجريبية موجودة في مصفوفة `products` داخل `script.js`.

هذه النسخة واجهة Front-End فقط. يمكن في المرحلة التالية إضافة لوحة تحكم، قاعدة بيانات، تسجيل طلبات، مخزون، ودفع إلكتروني.
